Get to know every part of the rakit.io editor: where it is, what it's for, and how to use it step by step. In the editor, the ⓘ button next to each feature also opens a short explanation.

F1Getting Started & the Editor

From signing up to knowing where every button on the screen is.

Sign up & log in

  1. Open the rakit.io home page and click Sign up. Fill in a username, email and password — or choose Continue with Google.
  2. Right after signing up, your first website is live at yourname.rakit.io and the editor opens automatically.
  3. New accounts get a one-time AI credit bonus, plus free credits every day (see Credits & Plans).
🔐 Accounts registered with email + password keep logging in with their password, even if the email matches your Google account. Accounts aren't merged automatically, for security.

Two editor layouts: Simple & Coding

Choose with the switch at the top center. Your choice is remembered in the browser.

✦ Simple

Just the AI chat and the preview. Great when you'd rather describe things to the AI and see the result without touching code.

</> Coding

The full layout: file panel, code editor, database, functions, diagrams, history and console. Features that need this layout switch you to Coding automatically.

F2Projects — Many Websites in One Account

Each project is a separate website with its own address, files, database, version history and AI conversations.

Creating a new project

  1. Click the folder button in the website address chip (top left).
  2. Choose New project.
  3. Enter the website address (lowercase letters, digits, -), e.g. bakery → bakery.rakit.io.
  4. Enter a project name (optional), then Create project.

Switch, rename, delete

  • Switch project: click the folder button and pick a project from the list.
  • Rename project…: changes the display name (the address stays).
  • Delete this project…: deletes its files, database and history. Your last project can't be deleted.
ItemDetails
Number of projectsAt most 5 per account.
AI creditsBelong to the account and are shared by all projects.
File & database quotaCounted per project (size depends on your plan).
Running AI promptsOne prompt at a time per account, in any project.

F3Files, Folders & Images

Every part of your website is stored as a file in the left panel. index.html is the home page.

Creating & managing files

  • The New file / New folder buttons above the file list. Type a full path to create inside a folder, e.g. css/style.css.
  • Right-click (or the ⋯ button) on a file: Open, Preview this page, Copy public URL, Rename (F2), Delete (Del).
  • Right-click on a folder: New file, New folder, Upload images to that folder.
  • The Reload and Collapse all folders buttons are right next to them.

Uploading images

  • Click the Upload images button, right-click → Upload images…, or drag files straight into the file list.
  • Formats: .png .jpg .jpeg .gif .webp .svg .ico .avif — the file contents are checked, so other files with a renamed extension are rejected.
  • Names are tidied automatically (lowercase, spaces → -). If the name already exists: Replace, Save as new, or Skip.

Using images on a page

Click an image in the file panel to view it (pixel & file size), then copy its path, the <img> tag, or the CSS url().

💡 The AI knows the list of images in your project, so you can write: “use /images/hero.jpg as the hero section background”. The AI can't create or edit images — upload the images you need yourself.

F4Code Editor

A VS Code-style editor for changing HTML, CSS and JavaScript directly.

Saving

  • Auto-save (the switch below the editor): saves as you type, and the preview updates too.
  • Ctrl/⌘ S saves the active file · avatar menu → Save all.
  • When you close a tab with unsaved changes, you're asked: Save / Don't save / Cancel.

Code prediction (AI) — free

  • Pause typing for a moment → the AI suggests the continuation in gray text.
  • Tab accepts · Esc or keep typing to ignore.
  • Uses no credits (there's a daily limit). Turn it off in Settings.

Right-click → ✦ AI

  • Select a few lines of code, then right-click:
  • ✦ Ask AI to change this code — puts that code in the AI box.
  • ✦ Ask AI about this code — for an explanation.
  • The request isn't sent right away; you can complete it first.

Search & navigation

  • Ctrl/⌘ F finds in the file · Ctrl/⌘ B shows/hides the file panel.
  • The breadcrumb above the editor shows where the file is.
  • The bottom bar: cursor position and the file's language.

📖 Code Walkthrough — the AI explains your code (free)

The Code Walkthrough button above the editor (for .html, .css and .js files) opens an explanation panel next to the editor. The AI explains the code in the order it runs, not line by line.

  1. Open a file and click Code Walkthrough. Wait while the AI puts the steps together.
  2. Each step has a title, a kind (start, decision, loop, waiting for action, request…), the lines involved, an explanation, a real-value example, and key terms (click one to see its meaning).
  3. Click a step → its lines are highlighted in the editor. Click a line in the editor → its step opens. Use the ‹ › buttons, ▶ (autoplay), or the arrow keys.
  4. Steps that refer to another file (a page, a CSS class, an /api/fn/… function) can be clicked to open it, then ← Back.
  5. Also see the flow diagram, notes (bugs, needs checking, suggestions) and code speed. Use Ask the AI to ask about the open step.
💾 Explanations are saved per file. Reopening the same file doesn't ask the AI again. When the file changes, the panel shows a notice and a Refresh button. Free, with a daily limit per account.

🎯 Select blocks — change only specific parts

Instead of describing “the part below the second heading…”, point at it directly in the preview.

  1. Click Select blocks above the preview.
  2. Hover over the page, then click the part you want to change (max. 5 blocks, across several pages if you like — change pages with the links in the preview).
  3. Click Write instruction. The selected blocks appear above the AI box.
  4. Write the change, e.g. “make it 3 columns and add icons”, then send. The AI focuses on those blocks and leaves the rest alone.
  5. Click Done to leave selection mode.

✏️ Edit — change text & images right in the preview

For changing headings, paragraphs, button labels, list items or images without opening the code and without using AI credits.

  1. Click Edit above the preview.
  2. Hover over the page — editable text gets a blue box — then click the text and type.
  3. Press Enter or click elsewhere to save. Esc cancels.
  4. Click Done to leave edit mode.

The change is written to that page's HTML file (e.g. index.html) at exactly the same spot — formatting such as bold or links inside the text is kept. The file also opens in the Code tab, so you can undo with Ctrl/⌘ Z. Text written by JavaScript (e.g. the message 'Password must be at least 6 characters.' in script.js) can be changed too — the string is replaced in that JS file. Text assembled from data (e.g. “You've clicked 3 times”) can't: clicking it shows a red marker, so change it in the code or ask the AI. To change pages: Alt+click a link.

Replacing images: in Edit mode, click the image. Pick another image from the project, click Upload a new image…, or paste an image address (https://…). Also fill in the alt text — a short description of the image for screen readers and search engines — then Save. Only <img> images can be replaced here; CSS background images and <picture> images with several versions are changed in the code or with the AI.

F6AI Assistant (Builder & Plan)

Open the AI tab or press Ctrl/⌘ I. Prompt-writing techniques are in Part 2.

🔨 Builder

The AI writes/changes/deletes files and creates database tables directly.

  1. Choose Builder below the prompt box.
  2. Write your request and press Enter (Shift+Enter = new line).
  3. Watch the progress & the list of changed files. Click a file to see the differences.
  4. Choose Save to accept or Undo to roll everything back.

🧭 Plan

The AI only discusses & drafts a plan, without changing files.

  1. Choose Plan and describe your idea.
  2. Go back and forth until the plan is right.
  3. Press Run this plan — the AI switches to Builder and carries it out.

F7Database (Data Tab)

Store visitor data & content permanently — like a spreadsheet, ready to use from your web pages.

Creating a table

  1. Open the Data tab and click + (New table) or + Create table.
  2. Enter a table name (e.g. messages), then add columns: a name, a type, tick Required if it must be filled, and Private if visitors must not see it.
  3. Click Create table. The id and created_at columns are created automatically.
💡 Faster: ask the AI in Builder mode — “build a guestbook with a name and message form” — and the table and its page are created together.

Column types

TypeForExample value
TextNames, messages, addresses (max. 10,000 characters)Budi
NumberPrices, quantities, scores150000
Yes/NoAttending, agreed, paidtrue / false
DateBirthdays, event schedules2026-12-31 or 2026-12-31T19:00
RelationPoints to a row in another table (e.g. order → product)12 (the target row's id)
ImageProduct photos, avatars, payment receipts/uploads/products/abc.jpg
⚠️ A column's type can't be changed after it's created. Column & table names can be changed (click the name, edit it, press Enter).

Access: who may do what

Click Settings on a table. Each operation can be Public (every visitor) or Only you (the owner, through the editor). By default everything is Only you.

OperationMeaningUsual advice
listRead a list of recordsPublic for guestbooks, catalogs, leaderboards
viewRead one recordPublic for product detail pages
createAdd recordsPublic for contact forms, RSVPs, orders
updateChange recordsOnly you (visitors are anonymous)
deleteDelete recordsOnly you

Private columns are never sent to visitors even when list is public — good for emails, phone numbers and addresses.

Managing table contents

  • + Row adds data by hand. Double-click a cell to edit it. The trash icon deletes a row.
  • Image columns show a thumbnail; double-click to upload, replace or clear it (you can also paste an https://… address).
  • Lots of data is split into pages — use the Previous / Next buttons.
  • The Use on your website section shows ready-to-copy example code (reading, adding, updating, deleting, handling errors) and flags access that isn't public yet.
  • Delete table is in the table settings — click once more to confirm.

F8Serverless Functions (Backend)

JavaScript code that runs on the server, not in the visitor's browser — for secret API keys, calculations that mustn't be tampered with, notifications, or calling other services.

Creating & trying a function

  1. Open the Functions tab and click + New function. Give it a name (lowercase letters, digits, - or _, max. 40), e.g. send-message.
  2. The file functions/send-message.js is created with example code. Click Open code to change it.
  3. Click Try: choose a method, fill in the query & JSON body, then run it. The result, status, time and console.log output appear right away.
  4. Call it from your web pages at /api/fn/send-message. Copy URL copies the full address.
💡 Or click ✦ Create with AI and describe the function, e.g. “send a Telegram notification for every new message from the contact form”.

Secrets, schedules and logs

🔑 Secrets (env)

Enter a name (e.g. TELEGRAM_TOKEN) and its value, then click Save. Read it in code with env.TELEGRAM_TOKEN. The value isn't shown in the editor again.

⏱ Schedules Pro / Unlimited

Click Schedule on a function: every 5/15/30 minutes, every hour, every day at a set time, every week, or a custom cron (WIB time, UTC+7). Most frequent: Pro every 15 minutes, Unlimited every 5 minutes.

📜 Execution log

The latest executions (triggered by visitors, tests or schedules) with status, duration, errors and console output. Failed executions have a ✦ Fix with AI button.

📊 Quota

The meter above the tab shows today's executions. Limits: 10 seconds & 64 MB per execution.

F9AI in Functions (AI Providers)

Build AI features into your website — chatbots, summaries, data extraction, image checks — using your own API key.

Adding a provider

  1. Functions tab → the AI providers section → add a provider.
  2. Choose a type: OpenAI, Anthropic Claude, Google Gemini, or OpenAI-compatible (with quick buttons for DeepSeek, Groq, OpenRouter, Mistral and Together).
  3. Fill in a name (used in your code), the API key, a chat model, and an embedding model (optional). Mark one as the default.
  4. Click Save & test to make sure the key and model work. Max. 10 providers per project.
CallResult
ai.chat(prompt, { system, images, provider, model, temperature, maxTokens }){ text, model, provider, usage }
ai.json(prompt, shape)An object in the requested shape
ai.embed(text | [text])Vectors for meaning-based search (Anthropic has no embeddings)
ai.similarity(a, b)How similar two vectors are (0–1)
ai.providers()The installed providers (without keys)
🛡️ Your API key is safe. Keys are stored on the server, never sent to the browser or to function code (the editor only shows the last 4 characters), and are deleted when the provider is removed. The provider bills your account — rakit.io doesn't deduct credits. Set a spending limit in the provider's dashboard.

Limits: max. 5 ai.* calls per execution, 60 seconds per call, max. 4 images (5 MB). Time spent waiting for the AI doesn't count toward the function's 10-second limit. Usage per provider is shown in the Functions tab.

F11Version History

A “save point” for all your project files. Experiment without fear of breaking things.

When versions are saved

  • Automatically when you start editing (at most every 10 minutes).
  • Automatically before the AI changes files.
  • Automatically before restoring a version (so even a restore can be undone).
  • Manually: the Save version now button, with your own name, e.g. “before redesign”.

Restoring

  1. Open the History tab and choose a version.
  2. Look at the files labeled Changed, Deleted, or New file. Click View differences.
  3. Restore this file for one file, or Restore this version for the whole project.
⚠️ The database isn't included in saves/restores, so data submitted by visitors isn't lost. Restoring the whole project also deletes files created after that version.

F13Publishing: Live or Dev/Prod

Control when visitors see your changes. Open the avatar menu → Publishing mode.

⚡ Live instantly default

Every change appears on yourname.rakit.io right away. Great for learning and experimenting.

🚀 Manual publishing (dev/prod)

You edit the dev version at yourname--dev.rakit.io (you can share it to get feedback). The public website only changes when you press Publish. The dev database is separate, for testing.

Publishing changes

  1. A dot on the Publish button (top right) means there are changes that aren't live yet.
  2. Click the button — you'll see the list of new, changed and deleted files, plus database structure changes.
  3. Click Publish. Data & images submitted by visitors on the public website stay safe; dev test data isn't copied.
  4. If a table/column will be deleted, tick the confirmation first — its data will be removed from the public website.
⚠️ Switching from manual back to live instantly makes unpublished changes go live right away, and the test data in dev is replaced by the real data from the public website.
