Inside the editor

Everything you need to learn while you build

One place to write code, ask the AI, see the result, and share your website.

A VS Code-style code editor

Write HTML, CSS and JavaScript with syntax highlighting, autocomplete, and autosave.

You learn: to use the same tools real programmers use.

AI assistant

Builder mode creates and changes files for you. Plan mode is for discussion and questions without changing anything.

You learn: to review the code the AI writes before you keep it.

Live preview

Every change shows up instantly. Try your site at desktop, tablet and phone sizes.

You learn: how code turns into what you see, and responsive design.

Hassle-free database

Create tables like a spreadsheet, then use them from your website for a guestbook, forms, or a product list.

You learn: how websites save and read data.

AI-drawn diagrams

ERDs, site maps, data flows, Use Case, Activity, Sequence, Class and State diagrams drawn by AI from your project.

You learn: to see your website's structure the way a system designer does.

Your own AI

Connect an OpenAI, Claude, DeepSeek, Groq, OpenRouter or Ollama API key in the AI Providers tab — use it as much as you like without touching your daily allowance.

You learn: how apps connect to AI services through an API.

Version history

Your project is saved automatically as versions, including before the AI changes files. Compare and restore at any time.

You learn: to experiment without fear, because you can always go back.

Instantly online

Every project gets its own address, like yourname.rakit.io, that you can share with anyone.

You learn: how a website reaches visitors on the internet.

Learning guide

Step-by-step guides and example prompts for the AI, perfect for getting started.

You learn: to turn an idea into a website, one step at a time.
