Panduan Fitur

Kenali setiap bagian editor rakit.io: di mana letaknya, apa gunanya, dan cara memakainya langkah demi langkah. Di editor, tombol ⓘ di samping setiap fitur juga membuka penjelasan singkatnya.

F1Memulai & Mengenal Editor

Dari daftar akun sampai paham letak setiap tombol di layar.

Daftar & masuk

  1. Buka halaman depan rakit.io, klik Daftar. Isi username, email, dan password — atau pilih Lanjutkan dengan Google.
  2. Setelah daftar, website pertamamu langsung online di namamu.rakit.io dan editor terbuka otomatis.
  3. Akun baru mendapat bonus kredit AI sekali pakai, ditambah kredit gratis setiap hari (lihat Kredit & Paket).
🔐 Akun yang didaftarkan dengan email + password tetap masuk memakai password, walaupun emailnya sama dengan akun Google-mu. Akun tidak digabung otomatis demi keamanan.

F2Project — Banyak Website dalam Satu Akun

Setiap project adalah website terpisah: alamat, file, database, riwayat versi, dan percakapan AI sendiri.

Membuat project baru

  1. Klik tombol folder di chip alamat website (kiri atas).
  2. Pilih Project baru.
  3. Isi alamat website (huruf kecil, angka, tanda -), mis. tokokue → tokokue.rakit.io.
  4. Isi nama project (opsional), lalu Buat project.

Ganti, ganti nama, hapus

  • Ganti project: klik tombol folder, pilih project dari daftar.
  • Ganti nama project…: mengubah nama tampilan (alamat tetap).
  • Hapus project ini…: menghapus file, database, dan riwayatnya. Project terakhir tidak bisa dihapus.
HalKeterangan
Jumlah projectMaksimal 5 per akun.
Kredit AIMilik akun, dipakai bersama semua project.
Kuota file & databaseDihitung per project (besarnya mengikuti paket).
Prompt AI berjalanSatu prompt sekaligus per akun, di project mana pun.

F3File, Folder & Gambar

Semua bagian website tersimpan sebagai file di panel kiri. index.html adalah halaman utama.

Membuat & mengelola file

  • Tombol File baru / Folder baru di atas daftar file. Tulis path lengkap untuk membuat di dalam folder, mis. css/style.css.
  • Klik kanan (atau tombol ⋯) pada file: Buka, Preview halaman ini, Salin URL publik, Ganti nama (F2), Hapus (Del).
  • Klik kanan pada folder: File baru, Folder baru, Upload gambar ke folder itu.
  • Tombol Muat ulang dan Tutup semua folder ada di sebelahnya.

Upload gambar

  • Klik tombol Upload gambar, klik kanan → Upload gambar…, atau seret file langsung ke daftar file.
  • Format: .png .jpg .jpeg .gif .webp .svg .ico .avif — isi file diperiksa, jadi file lain yang diganti ekstensinya ditolak.
  • Nama dirapikan otomatis (huruf kecil, spasi → -). Bila nama sudah ada: Ganti, Simpan sebagai baru, atau Lewati.

Memakai gambar di halaman

Klik gambar di panel file untuk melihatnya (ukuran piksel & file), lalu salin path, tag <img>, atau url() CSS.

💡 AI tahu daftar gambar di project-mu, jadi kamu bisa menulis: “pakai gambar /images/hero.jpg sebagai latar bagian hero”. AI tidak bisa membuat atau mengubah gambar — upload sendiri gambar yang dibutuhkan.

F4Editor Kode

Editor ala VS Code untuk mengubah HTML, CSS, dan JavaScript secara langsung.

Menyimpan

  • Auto-save (sakelar di bawah editor): tersimpan sendiri saat mengetik, preview ikut berubah.
  • Ctrl/⌘ S simpan file aktif · menu avatar → Simpan semua.
  • Saat menutup tab yang belum tersimpan, kamu ditanya: Simpan / Jangan simpan / Batal.

Prediksi kode (AI) — gratis

  • Berhenti mengetik sebentar → AI menebak lanjutannya dalam teks abu-abu.
  • Tab menerima · Esc atau lanjut mengetik mengabaikan.
  • Tidak memakai kredit (ada batas harian). Matikan di Pengaturan.

Klik kanan → ✦ AI

  • Blok (pilih) beberapa baris kode, lalu klik kanan:
  • ✦ Minta AI mengubah kode ini — mengisi kotak AI dengan kode itu.
  • ✦ Tanya AI tentang kode ini — untuk penjelasan.
  • Permintaan tidak langsung dikirim; kamu bisa melengkapinya dulu.

Cari & navigasi

  • Ctrl/⌘ F cari di file · Ctrl/⌘ B tampil/sembunyi panel file.
  • Breadcrumb di atas editor menunjukkan lokasi file.
  • Bilah bawah: posisi kursor dan bahasa file.

📖 Baca Alur Kode — AI menjelaskan kodemu (gratis)

Tombol Baca Alur Kode di atas editor (untuk file .html, .css, .js) membuka panel penjelasan di samping editor. AI menjelaskan kode berurutan seperti saat dijalankan, bukan urut baris.

  1. Buka file, klik Baca Alur Kode. Tunggu AI menyusun langkah-langkahnya.
  2. Setiap langkah berisi judul, jenis (mulai, keputusan, perulangan, menunggu aksi, permintaan…), baris yang terlibat, penjelasan, contoh nilai nyata, dan istilah penting (klik untuk melihat artinya).
  3. Klik langkah → barisnya disorot di editor. Klik baris di editor → langkahnya terbuka. Pakai tombol ‹ ›, ▶ (putar otomatis), atau panah keyboard.
  4. Langkah yang merujuk file lain (halaman, class CSS, fungsi /api/fn/…) bisa diklik untuk membukanya, lalu ← Kembali.
  5. Lihat juga diagram alur, catatan (bug, perlu dicek, saran), dan kecepatan kode. Pakai Tanya AI untuk bertanya tentang langkah yang sedang dibuka.
💾 Hasil penjelasan disimpan per file. Membuka ulang file yang sama tidak bertanya ke AI lagi. Bila isi file berubah, panel memberi tanda dan tombol Perbarui. Gratis, dengan batas harian per akun.

🎯 Pilih blok — ubah bagian tertentu saja

Daripada menjelaskan “bagian yang di bawah judul kedua…”, tunjuk langsung bagiannya di preview.

  1. Klik Pilih blok di atas preview.
  2. Arahkan kursor ke halaman, lalu klik bagian yang ingin diubah (maks. 5 blok, boleh dari beberapa halaman — pindah halaman lewat link di preview).
  3. Klik Tulis perintah. Blok terpilih muncul di atas kotak AI.
  4. Tulis perubahannya, mis. “jadikan 3 kolom dan beri ikon”, lalu kirim. AI fokus ke blok itu dan tidak mengubah bagian lain.
  5. Klik Selesai untuk keluar dari mode memilih.

✏️ Edit — ubah tulisan & gambar langsung di preview

Untuk mengganti judul, paragraf, label tombol, isi daftar, atau gambar tanpa membuka kode dan tanpa memakai kredit AI.

  1. Klik Edit di atas preview.
  2. Arahkan kursor ke halaman — teks yang bisa diubah diberi kotak biru — lalu klik teksnya dan ketik.
  3. Tekan Enter atau klik di tempat lain untuk menyimpan. Esc membatalkan.
  4. Klik Selesai untuk keluar dari mode edit.

Perubahan ditulis ke file HTML halaman itu (mis. index.html) di tempat yang sama persis — format seperti tebal atau tautan di dalam teks tetap ada. File-nya ikut terbuka di tab Code, jadi bisa dibatalkan dengan Ctrl/⌘ Z. Teks yang ditulis JavaScript (mis. pesan 'Password minimal 6 karakter.' di script.js) juga bisa diubah — string-nya diganti di file JS itu. Teks yang dirakit dari data (mis. “Kamu sudah klik 3 kali”) tidak bisa: saat diklik muncul tanda merah, ubah lewat kode atau minta AI. Pindah halaman: Alt+klik link.

Ganti gambar: di mode Edit, klik gambarnya. Pilih gambar lain dari project, klik Upload gambar baru…, atau tempel alamat gambar (https://…). Isi juga teks alternatif (alt) — deskripsi singkat gambar untuk pembaca layar dan mesin pencari — lalu Simpan. Yang bisa diganti di sini hanya gambar <img>; gambar latar dari CSS dan gambar <picture> dengan beberapa versi diubah lewat kode atau AI.

F6Asisten AI (Builder & Plan)

Buka tab AI atau tekan Ctrl/⌘ I. Teknik menulis prompt ada di Bagian 2.

🔨 Builder

AI langsung menulis/mengubah/menghapus file dan membuat tabel database.

  1. Pilih Builder di bawah kotak prompt.
  2. Tulis permintaan, tekan Enter (Shift+Enter = baris baru).
  3. Lihat progres & daftar file yang diubah. Klik file untuk melihat perbedaannya.
  4. Pilih Simpan untuk menerima atau Batalkan untuk mengembalikan semuanya.

🧭 Plan

AI hanya berdiskusi & menyusun rencana, tanpa mengubah file.

  1. Pilih Plan, ceritakan idemu.
  2. Tanya-jawab sampai rencananya pas.
  3. Tekan Jalankan rencana ini — AI pindah ke Builder dan mengerjakannya.

  • 🕘 Riwayat percakapan (ikon jam): buka percakapan lama untuk melanjutkannya.

💰 Kredit aman. Kredit dipotong saat prompt dikirim, dan dikembalikan bila prompt gagal, kamu hentikan, atau antrean penuh. Sebelum AI mengubah file, versi otomatis disimpan di Riwayat.

F7Database (Tab Data)

Simpan data pengunjung & konten secara permanen — mirip spreadsheet, langsung bisa dipakai dari halaman website.

Membuat tabel

  1. Buka tab Data, klik + (Tabel baru) atau + Buat tabel.
  2. Isi nama tabel (mis. ucapan), lalu tambahkan kolom: nama, tipe, centang Wajib bila harus diisi, dan Privat bila tidak boleh terlihat pengunjung.
  3. Klik Buat tabel. Kolom id dan created_at dibuat otomatis.
💡 Lebih cepat: minta AI di mode Builder — “buat buku tamu dengan form nama dan pesan” — tabel dan halamannya dibuat sekaligus.

Akses: siapa boleh apa

Klik Atur pada tabel. Setiap operasi bisa Publik (semua pengunjung) atau Hanya kamu (pemilik, lewat editor). Bawaannya semua Hanya kamu.

Kolom Privat tidak pernah dikirim ke pengunjung walau list publik — cocok untuk email, nomor HP, alamat.

Mengelola isi tabel

  • + Baris menambah data manual. Klik dua kali sel untuk mengubah. Ikon tempat sampah menghapus baris.
  • Kolom gambar tampil sebagai thumbnail; klik dua kali untuk upload, ganti, atau kosongkan (bisa juga tempel alamat https://…).
  • Data banyak dibagi per halaman — pakai tombol Sebelumnya / Berikutnya.
  • Bagian Pakai di websitemu menampilkan contoh kode siap salin (membaca, menambah, mengubah, menghapus, menangani error) dan memberi tanda bila aksesnya belum publik.
  • Hapus tabel ada di pengaturan tabel — klik sekali lagi untuk memastikan.

F8Fungsi Serverless (Backend)

Kode JavaScript yang berjalan di server, bukan di browser pengunjung — untuk kunci API rahasia, perhitungan yang tidak boleh diakali, notifikasi, atau memanggil layanan lain.

Membuat & mencoba fungsi

  1. Buka tab Fungsi, klik + Fungsi baru. Beri nama (huruf kecil, angka, - atau _, maks. 40), mis. kirim-pesan.
  2. File functions/kirim-pesan.js dibuat dengan kode contoh. Klik Buka kode untuk mengubahnya.
  3. Klik Coba: pilih method, isi query & body JSON, lalu jalankan. Hasil, status, waktu, dan console.log tampil langsung.
  4. Panggil dari halaman website lewat /api/fn/kirim-pesan. Salin URL menyalin alamat lengkapnya.
💡 Atau klik ✦ Buat dengan AI dan ceritakan fungsinya, mis. “kirim notifikasi Telegram setiap ada pesan baru dari form kontak”.
